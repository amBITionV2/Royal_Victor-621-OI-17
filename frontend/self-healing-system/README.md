# Self-Healing AI System

## Overview
AI-powered self-healing system for cloud-native apps.  
Detects pod failures, scales services, and isolates regions automatically.

## Demo
1. Run `streamlit run ui/app.py`
2. Click "Analyze & Heal" to simulate failure detection and remediation.
3. GitHub Actions workflow can also simulate healing automation.

## Tech Stack
- Python, Streamlit
- CrewAI Agents
- Pipelines for pod restart, scaling, region isolation
- GitHub Actions for automation
